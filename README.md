# Sales Performance & Time Intelligence Dashboard

## Project Overview

This project is an interactive **Sales Performance Dashboard built using Power BI**. The main objective is to analyze sales performance over time and provide key metrics using **DAX time-intelligence calculations**.

The dashboard focuses on tracking sales performance through metrics such as **Total Sales, MTD, YTD, and Variance**.

> **Note:** This is a hands-on practice project recreated by following a Power BI tutorial to strengthen practical skills in Power Query, DAX, data modeling, and dashboard development.

## Tools & Technologies

* **Power BI**
* **Power Query**
* **DAX**
* **Excel** – Data Source

## Dataset

The project uses a practice sales dataset provided with the tutorial/project resources.

The dataset was imported into Power BI and prepared for analysis before creating the dashboard.

## Data Preparation

The data was cleaned and transformed using **Power Query**.

Key preparation activities included:

* Checking and correcting data types
* Cleaning and formatting data
* Removing unnecessary data
* Preparing date-related fields for time-based analysis
* Structuring the data for reporting

## Data Modeling

The prepared data was modeled in Power BI to support the dashboard calculations and visualizations.

The model was designed to allow the DAX measures to calculate sales performance across different time periods.

## DAX & Time Intelligence

DAX measures were created to analyze sales performance over time.

### Key Measures

* **Total Sales**
* **Month-to-Date (MTD) Sales**
* **Year-to-Date (YTD) Sales**
* **Variance**

These measures allow users to compare sales performance across different periods and understand changes in performance.

## Dashboard Features

The dashboard includes:

* **New Card visuals** for displaying important metrics
* Sales performance visualizations
* MTD and YTD analysis
* Variance analysis
* Interactive slicers
* Time-based analysis

The interactive elements allow users to change the selected time period and analyze the corresponding sales performance.

## Key Analysis

The dashboard helps users:

* Monitor overall sales performance
* Track **Month-to-Date (MTD)** sales
* Track **Year-to-Date (YTD)** sales
* Analyze **sales variance**
* Identify changes in sales performance over time
* Compare performance across different time periods
