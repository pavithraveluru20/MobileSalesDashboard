# Mobile Sales Performance Dashboard | Power BI

## Project Overview

This project is an interactive **Mobile Sales Performance Dashboard built using Power BI**. The dashboard focuses on analyzing sales performance over time using key metrics such as **Total Sales, MTD, YTD, and Actual vs Target Variance**.

The project demonstrates the complete Power BI workflow, including data preparation, data modeling, DAX calculations, time-intelligence analysis, and interactive dashboard development.

> **Note:** This is a hands-on practice project recreated by following a Power BI tutorial to strengthen practical skills in Power BI, Power Query, DAX, and dashboard development.

## Tools & Technologies

* Power BI
* Power Query
* DAX
* Excel

## Dataset

The project uses an **Actual vs Target sales dataset** containing sales-related information required for performance and time-based analysis.

The dataset was imported into Power BI and prepared for analysis using Power Query.

## Data Preparation

Data preparation was performed using **Power Query**, including:

* Checking and correcting data types
* Cleaning and formatting the data
* Preparing date fields for time-based analysis
* Transforming the data into a suitable format for reporting

## DAX & Time Intelligence

DAX measures were created to analyze sales performance across different time periods.

### Key Measures

* Total Sales
* Month-to-Date (MTD) Sales
* Year-to-Date (YTD) Sales
* Actual Sales
* Target Sales
* Variance

These measures help compare actual sales performance against targets and analyze changes over time.

## Dashboard Features

The dashboard includes:

* New Card visuals for key metrics
* MTD and YTD sales analysis
* Actual vs Target comparison
* Variance analysis
* Time-based sales analysis
* Interactive slicers and filters
* Sales performance visualizations

## Key Analysis

The dashboard helps users:

* Monitor overall sales performance
* Track MTD and YTD sales
* Compare actual sales against targets
* Analyze sales variance
* Identify changes in performance over time
* Interactively filter and explore sales data
